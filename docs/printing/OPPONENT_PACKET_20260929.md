# 対戦大学の一括資料（2026-09-29）

## 操作と構成

投球検索で大学を選ぶと「対戦大学の資料を一括印刷」を表示。現在の検索条件を適用し、その大学の投手・打者だけを一覧にする。選手の個別選択・全選択と、4種類の資料選択が可能。

- 投手：対左・対右打者で各A4縦1ページ。球種別の平均／最高球速、平均縦横変化、カウント別投球分析。
- 打者：既存の左右別打者分析を再利用、A4横1ページ。
- 大学一覧：FS直球Swing、FS変化球Swing、外変Swing、外変Whiff、引張／中堅／逆方向。大学全体と選択打者、10人ごとに改ページ。
- 打球方向：対左／対右投手×ストレート／変化球の4図、A4横1ページ。通常の分析タブにも追加。

印刷プレビューと印刷は同じDOM。縦横の名前付きページを使用し、既存の空白・見切れ・未描画検査と印刷停止条件を維持。連番と作成日時を全ページに付ける。

## 集計の根拠

- 内角ストレート：既存の投球位置座標で、右打者はplateX >= 0.254/3、左打者はplateX <= -0.254/3。ゾーン内角1/3と、さらに内側のボール球を含む。高さの条件なし。割合は各投球前カウントの全球数が分母、内角直球数／全球数を併記。位置不明は内角の分子に含めない。
- FS：元の打席全体で最初のストライク相当球を特定してから検索条件で絞る。初球と混同せず、絞り込み後に再判定しない。
- 直球はストレートのみ。シンカー・カット等の判別できた他球種は変化球、その他／不明は両分類から除外。
- 外変：右打者plateX < -0.25、左打者plateX > 0.25の変化球。Swingの分母は対象球数、Whiffの分母は対象を振った回数。
- 打球方向は捕手視点、バントを除く±45度のインプレー打球。中堅は±15度、引張側は打者左右で反転。方向比率は距離欠測も含め、方向図は距離が測定された打球のみ。4図は同じ距離尺度。
- ゴロは細点線、ライナーは実線、フライ／ポップアップは長点線。安打（本塁打含む）は赤、それ以外は黒。打球種別不明は終点だけ表示。

## 実施済みの検証

- 型検査成功。
- 集計・印刷判定・実データ打者の関連テスト10件成功。捕手視点・左右の回帰テスト7件成功。
- 立正大学2026秋の既存資料との照合：FS直球59%（60/101）、FS変化球53%（39/73）、外変Swing38%（41/107）、外変Whiff37%（15/41）が一致。
- クラウドChromeの実画面：投手1人・打者1人の5ページ、全投手9人・全打者15人の50ページを生成。50ページは最終書式で空白・はみ出し検査を通過、印刷ボタン有効。
- 左右別打球方向タブから三好元気の単独印刷を生成。A4横1ページ、空白・はみ出し検査を通過し、4図と線種・色の凡例を画面確認。
- 縦196×282mm・横283×195mmのページと連番をDOMで確認。球種表の列幅と行間を修正。

## 同日追記：変化量の表示項目

ユーザー指定により、カウント別投球分析に付く球種表から最大縦変化・最大横変化の2列を削除。変化量は平均のみ、球速は平均／最高。左右とも同じ書式を使用する。上記のブラウザ検証は8列版での結果であり、この6列版の実画面・実印刷の確認結果ではない。
