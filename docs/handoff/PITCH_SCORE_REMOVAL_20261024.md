# PITCHスコアの表示停止

2026-10-24のユーザー依頼により、総合投球スコア・球質スコア・コーススコアを一旦削除。

- PCメニュー、スマホメニュー、ホーム、フッター、専用ページ、投手詳細タブ、概要、球種表、大学別比較、ランキング、用語集から除外。
- 表示用データと公開分析APIでは保存済みスコアとそのパーセンタイルも除外。再読込時の旧モデルの再計算を停止。
- 旧qualityページはホーム、旧pitching_percentile／pitching_expectedランキングは奪三振ランキング、保存済みのPITCHスコア詳細タブは概要へ切替。
- ホームの投手一覧は奪三振数。球種別球速表は平均球速順。球速・回転・変化量などの実測指標、打撃・捕手指標は維持。
- 元CSV・保存済み集計・投球軌道データは公開194のソースと一致。過去モデルの計算コードを残し、将来の検討に備える。
- 関連テスト76件成功。指標解説、画面の静的描画、旧URL、公開API、オフライン読込、過去3シーズンの実測・実績値保持を検証。型検査成功。
- 内部プレビューの実ブラウザでホーム、投手詳細、旧ランキングURLの切替とスコア非表示を確認。実機印刷・スマホ実機は未実施。

標準Sitesビルドの完了後に、現在の公開範囲を保って公開する。認証・D1/R2・データ保存方式は変更しない。
