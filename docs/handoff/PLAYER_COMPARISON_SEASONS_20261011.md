# 選手比較のシーズン個別選択

「選手を横並び」の3枠に、それぞれ独立したシーズンと投手の選択欄を追加。現在の登録シーズン（2026秋・2026春・2025秋）をカタログから取得するため、新シーズンも同じ仕組みで候補に入る。

- 各列は選んだシーズンの `pitchers` と `pitchTypes` を使用する。識別キーはシーズンと選手IDの組合せ。同じ投手を別シーズンで並べられる。
- 同一シーズンの同一投手を重ねて選ぶと、以前の枠を空にする。シーズン変更時はその枠の投手を選び直す。
- 表の選手名・大学とともにシーズンを表示。選手名から開く詳細も対象シーズンに切り替える。
- 従来のURL/セッション状態に `seasons` 配列を追加。古い保存状態は従来の画面シーズンを3枠に適用する。
- 他シーズンは選ばれた分だけ共通データローダーで取得する。未取得・読込失敗時に他シーズンの数値を代用しない。古いリクエストの完了は新しい選択へ反映しない。再読み込み操作と既存の保存済みデータ通知に対応。
- DELTA VIEW・データ本体・指標定義は維持。

検証: `node --experimental-strip-types --test tests/player-comparison.test.ts tests/player-comparison-ui.test.mjs tests/view-state.test.ts tests/dataset-loading.test.ts tests/catalog-refresh.test.mjs` — 20件成功。実データの東恩納（2026秋）と中西（2025秋）、同一IDの別シーズン、登録終了選手、球種欠測、選択条件復元、ReactのHTML出力を確認。

既存の `tests/batting-ui.test.mjs` 20件も成功（DELTA VIEWの期間表示・選手詳細・ホーム等）。型検査、公開用buildと成果物検査も成功。
