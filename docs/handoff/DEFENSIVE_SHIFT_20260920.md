# 守備シフトの前後・投手左右別判定

- lib/defensive-shift.ts に集計を分離。外野3方向別の前進・標準・後退・データ不足維持を追加。
- 打球速度・角度の近い他打者の距離と実測距離を併用。選択シーズン、対戦投手左右、方向を合わせて比較。同一打者を比較母集団から除外。
- 5球未満または比較対象20球未満は維持。5〜9球は参考候補。深い打球の割合が15%超なら前進を抑制。
- 閾値は配置候補を抽出する独自ルール。守備開始位置や捕球可能性の検証済み最適化モデルではない。図の移動は模式表示であり距離指定ではない。
- SHIFT と打者詳細で左右合算・対右・対左を切替。数値表と判定方法は折り畳み。
- 春季大城戸は左翼前進の参考候補。対右4球は維持、対左の左翼5球は前進。秋季は不足で維持。

検証: 型検査・本番ビルド、守備シフト4テスト、既存図形3テストが成功。プレビューで春季、選手検索、対右/対左の配置・数値の更新と図表示を確認。
