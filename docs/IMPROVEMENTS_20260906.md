# Savant全体改善 2026-09-06

## 対象

東都サヴァントの印刷・型安全性・読み込み・データ公開経路・保守性。開始時点はNEWS更新を含む3c4eb2fbd1f36bf934ea5f57fcaf66691384443f。ユーザーから全項目の改善と、以後の公開確認不要の指示あり。編集は1人、読み取りレビュー2人で実施。Labのソースと受入条件はこの変更の対象外。

## 変更

- 全体型検査を修正。strictは維持し、Cloudflareの公式型とDOMストリームの境界を整理。ビルドにも型検査を追加。
- 静的シーズン/回転データを画面間で共有し、重複取得・解析を削減。失敗した取得は再試行可。古いシーズン応答が最新選択を上書きしない。
- 軽量配信形式を生成。数値を丸めず、全項目・null・欠損キー・投球順を保持。展開時の大量の中間配列を除去。
- アップロードデータを5秒で黙って諦める経路を修正。20秒の待機上限と明示的な失敗判定を設け、既存表示は保持。同梱データへ戻る場合は画面に明示。
- 回転分析とバレルゾーンを遅延読み込み。SWは未閲覧シーズンの自動取得をやめ、使用したデータを保存。管理・API・認証・CSVは対象外。
- 元CSV3ファイルを公開フォルダーからdata/rawへ移動し、内容をそのまま保持。管理者限定APIから初期CSVを復元配信。公開分析JSON・読取API・検索CSVの公開範囲は維持。
- 印刷CSSと指標説明、データ型/配信処理を画面本体から分離。元の印刷CSSの適用順序を維持。
- 印刷のフォント/画像待機を15秒で制限、閉じる操作で中止。初期化エラー後も再表示可能。ResizeObserverなしの環境に対応。CSS読取失敗時に取得代替。フッターのはみ出しも検査。
- 打者の速球Contact説明を、実際に比較した145～149km/hなどの球速帯へ修正。集計式・リーグ強打閾値は変更しない。
- READMEを実プロジェクトの構成・操作・データ公開範囲に更新。

- Chrome内部プレビュー: 春季11,943球の通常画面を表示。

## 計測

春季データのgzipサイズは1,296,224→1,007,607バイト（約22.3%減）。圧縮前JSONの削減率とは区別する。データ展開処理は中間配列の削減を実測で確認したが、端末やネットワークによる画面表示時間の一定倍率向上は保証しない。
