# 投球軌道の移植

2026-09-30、バレルゾーンのメニューを投球軌道へ置き換えた。
旧 `表示=barrel` は `trajectory` として読み、新しいメニューは `表示=trajectory` を使用する。個人打撃データやランキングのBarrel指標は維持する。

`public/trajectory-studio` は投球軌道スタジオv3の同一オリジン版。元ソースのcommitは `0003a93c7e4f373f4265d312ce748e4fb1adc0ba`。
`app/pitch-trajectory.tsx` がID東都側のシーズンを子画面へ渡す。埋め込み時は子側のブランドとシーズン選択を隠す。再生準備の通知は送信元window・origin・seasonを確認する。`barrel-zone.tsx` とエンジンは過去コード/既存テストとして保持するが画面には読み込まない。

## 引き継いだ仕様

- TrackManの9軌道係数とZoneTimeを使用。軌道・到達時間は変更しない。
- 捕手は参考ゾーン全体が入る倍率へ調整。打者は高さ1.50m、横0.34m、ホーム前縁から投手側0.25m、拡大9倍を初期値とする。
- 比較は最大5球。ゾーン内に到達する異球種を最大3球初期選択し、残りは真の空欄。
- 実時間/0.75倍等、白球と赤い縫い目、回転、実戦モード、目の位置調整、画像保存、数値画面を維持。
- 参考ゾーンは幅0.432m、高さ0.50–1.10m。球種は元CSVのTaggedPitchType。ID東都の球種再分類や分析用ゾーンを軌道へ無断適用しない。

## データ更新の範囲

現時点の3シーズン24,854球を移植した。`lib/generated/trajectory-studio.json` に各シーズンの球数・投手数・最終日を記録する。未収録シーズンは空表示。ID東都の球数が収録数と異なる場合は軌道データの収録範囲を表示する。

ID東都の公開summary/spinには9係数とZoneTimeが保持されていない。**この静的移植はR2のCSV追加と自動同期しない**。今後は原CSVから軌道用payloadを再生成するか、丸めない係数を共通取り込みへ追加した上で専用の公開feedを作る。通常集計を変更していないため、既存データ・import・バックアップ・計算定義への影響はない。

スクリプトURLには内容hashを付け、既存service workerのcache-firstでも修正版を区別する。親のシーズンが変わるとiframeを再作成し、立ち位置等は同一オリジンのlocalStorageへ保存する。
