# PITCHスコア v3 と操作改善

## 評価方法

- 基準50、標準化評価1単位につき20点。下限0、上限なし。
- 球種別は同シーズン・同球種の有効25球以上の投手を基準とする。3人未満なら10球以上へ広げる。それでも3人未満、または不明球種なら未評価。
- 球速・回転・エクステンション・IVB・横変化・進入角・到達位置がそろった球のみ使用する。欠損を0にしない。
- 従来の5要素の配分は45/15/15/15/10%。変化は標準化IVBと横変化の距離、進入角の方向補正も従来どおり。要素統合後の球質、位置評価、両者1:1の総合値をそれぞれ再標準化する。
- 球種別は `50 + 20*z*n/(n+20)`。10球未満は未評価、10〜24球は参考、25〜49球は信頼度中、50球以上は高（基準投手5人未満は中）。
- 投手総合は未縮小の球種評価を有効球数で加重する。100有効球以上の投手が3人以上いる場合に投手間で再標準化し、`50 + 20*z*n/(n+50)` とする。25有効球未満または評価可能球が全投球の80%未満なら未評価。球種得点の平均による再圧縮・二重縮小を避ける。
- 最良選手を必ず100、最低選手を必ず0にする処理はしない。同シーズン内の相対評価であり、異なるシーズンの絶対能力差や成績予測の検証済みモデルではない。
- `pitchingPlus` / `stuffPlus` / `locationPlus` のAPIキーは互換性のため維持し、名称・基準・メタデータを更新する。

## 反映経路

`lib/pitch-quality.mjs` をCSV取込・Google通知用エンジン・保存済みJSON読込・通常/圧縮静的読込・公開APIで共用する。選手詳細、球種、大学、ハイライト、3スコアのパーセンタイルも同じ値を使う。`metadata.pitchQuality.version` によって二重処理を防ぐ。

静的3シーズンと初期データはスコアだけを再計算した。元CSV、投球明細、試合記録、打撃成績、PitchValue等は変更しない。R2の旧保存版は書き換えず表示時に投影する。保存版の原本ダウンロード・復元時のハッシュは維持する。

## 6件の改善

1. 画面内の平均・標準偏差はnull/空欄/非数を除外。実測0は残す。位置・範囲検索も未計測を0として扱わない。
2. 個人PITCHスコアはシーズン全体と明示し、適用されない条件を隠す。条件は他の分析タブへ戻る際に保持。
3. 投球検索、ランキング、選手詳細、選手比較、PITCHスコアの状態をURLとセッションに保持。初回シーズンもURLに記録し、戻る/進む/再読込に対応。
4. 投球明細を250球ずつ前後ページへ移動できる。フィルター・CSV出力・分析は全一致投球が対象。
5. 個人画面から比較へ進む際は本人と投手/打者を引き継ぐ。少数標本の本人も選択肢から消えない。
6. 打者プロファイルで大学・選手を複数選択してA4横、1人1ページを生成。単独印刷と同じ計算・同じ印刷ページを再利用し、0人選択では実行不可。
