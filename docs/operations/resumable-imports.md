# CSV 取り込みの保存と再開

管理画面の「検証して反映」は、入力原本を先にサーバーへ保存します。日付から判定したシーズンごとに検証し、問題のない分を反映します。警告があるシーズンは確認待ちになります。

## 再開方法

- 「原本の保存が完了しました」と表示された後は、同じ管理者アカウントで別の端末から `/admin` を開き、「未完了の取り込み」から再開できます。
- 原本の保存中に中断した場合は、最初と同じ CSV を同じ順番で選択して再開します。名前・容量・ファイル全体の SHA-256 と保存済みチャンクを照合します。
- 画面を閉じると計算は停止します。閉じた画面で処理が継続する仕組みではありません。
- 「一時停止」は現在の通信・計算を止め、使用権を解除します。画面を閉じた場合や解除の応答が失われた場合は、最後の更新から最大 15 分後に別の画面で使用権を取得できます。
- 公開反映の開始後は、その結果を照合するまで中止できません。反映の応答を受け取れなくても、最新・過去の保存履歴から完了を確認します。既に反映された古い版を再び公開することはありません。
- 警告の確認操作は保存しません。検証の期限切れや別のデータ更新が発生した場合は、対象シーズンを再検証して改めて確認します。

## 保存と容量

原本は `import-jobs/v1/<所有者のハッシュ>/<ID>/sources/` に 1 MiB ずつ保存します。原本チャンクは上書きせず、保存後と読み出し時に照合します。認証済み管理者のサーバー側 ID（未提供時は許可済みメールアドレス）から所有者を決めます。クライアントから所有者を指定することはできません。

一度の取り込みは 128 ファイル、合計 512 MiB までです。年度や累計保存量の上限ではありません。大きい原本は試合ごとに分けて追加してください。集計に必要なメモリーは端末にも依存します。

シーズンごとの進行状態を R2 へ保存し、更新番号と使用権を照合します。複数端末からの同時操作や古い画面のチェックポイントを拒否します。公開反映には永続的な処理中マークを置き、中止が先行して後から公開される競合を防ぎます。

取り込みの完了・中止後は、再開用原本を削除します。公開済みの原本・更新履歴は既存の保存版に残ります。削除に失敗した場合は「原本の整理を再試行」が一覧に残ります。中止後に遅れて到着したアップロードも公開されず、削除を試みます。

未完了の取り込みは自動的に削除しません。不要になったジョブは管理画面で中止してください。再開用の R2 データは作業途中の保管であり、独立バックアップの対象となる公開保存版とは区別します。
