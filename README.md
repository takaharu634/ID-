# 投球軌道 VR

ID東都本体とは別の、静的なWebXR投球ビューアです。
WebXRのimmersive-vr対応を実行時に判定し、非対応端末では通常の3Dプレビューを使います。

## 開発

`npm ci` → `npm run build` → `npm test`

成果物は `dist/`。Three.js r180を同一オリジンに同梱し、CDNに依存しません。
HTTPSのトップレベルページから起動してください。通常表示のドラッグで見回せます。
VR操作はコントローラーのselect、またはコントローラー不在時の1.5秒の視線滞留です。
VRの開始は明示的なボタン操作からのみ実行します。

## 再現の範囲

- 元データ：投球軌道スタジオ由来の2025秋、2026春、2026秋、24,854球、163シーズン投手。
- 元モデルの多項式係数と到達時間、地面到達時の打ち切りを維持します。別の力学モデルは加えません。
- 元の座標は `[-TrackManZ(t), TrackManY(t), TrackManX(t)-TrackManX(ZoneTime)]`。
- 元の世界全体をY軸180度回転します。VRの投手方向は−Z、上は+Y、1単位は1mです。
- ホーム前縁をz=0にします。先端はVR z=+.432m。プレート前縁はz=−18.0084m。
- ボール半径は.0366m。元の閉じた縫い目、108組の糸、球種ごとの表示姿勢を使用します。
- SpinRate・SpinAxisまたはTiltで回転。ジャイロ角0と共通初期位相は表示上の仮定です。
- 投手の投球動作やフォームはデータに含まれず、再現しません。
- 初期球はゾーン内の実投球を最大3球選び、比較枠は5球です。初期は1球・軌道線なし・実時間。
- 目の高さはlocal-floorの実測値を維持します。localへ代替する場合は初回目の高さを1.50mに合わせます。
- 校正は水平方向の位置と向きだけを変更し、頭の上下・傾きの追従を上書きしません。
- 投球中は操作面を隠します。トリガーで一時停止・操作面を呼び戻せます。
- 元データは固定スナップショットです。ID東都の新CSVとは自動同期しません。

## 確認状況

軌道スナップショット、両打席の向き、床座標校正、回転の向き、物理時計、WebXRの開始/拒否/終了/再入場を自動検証します。
WebXRを模擬した試験はヘッドセット実機の立体感、遅延、フレームレートの確認を代替しません。
実機の機種は未指定・未検証です。

公開には `.openai/hosting.json` の既存project_idを使い、別のID東都プロジェクトへ配置しないでください。
